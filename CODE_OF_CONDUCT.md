# Code of Conduct

Canvas Prompt is an early local-first alpha. This project welcomes respectful
questions, bug reports, documentation fixes, workflow reports, and carefully
scoped contributions.

## Expected behavior

- Be respectful and specific.
- Discuss the work, evidence, and trade-offs without attacking people.
- Make room for contributors with different levels of experience.
- Remove private material before sharing logs, screenshots, or examples.
- Keep conversations on topic and move a new subject to a new issue or
  discussion.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Publishing credentials, private canvas data, recordings, transcripts,
  Prompt Packages, or sensitive information from screenshots.
- Deliberate spam, repeated unsolicited promotion, or disruptive
  cross-posting.
- Misrepresenting an experiment, local build, or private report as a public
  product result.

## Maintainer response

Maintainers may edit, hide, lock, close, or remove conversations that violate
this policy or the GitHub Community Guidelines. They may ask for a report to be
moved to a private channel when it contains security-sensitive information.
Maintainers will use their best judgment and do not promise a fixed response
time.

## Reporting

For security vulnerabilities, follow [SECURITY.md](./SECURITY.md) and do not
open a public issue with exploit details or private material. For community
conduct concerns, contact the repository owner privately through GitHub.

## Scope

This policy applies to the Canvas Prompt repository, its issues, pull
requests, discussions, and project-related public spaces when a person is
representing the project.

This policy is intended to complement GitHub's [Community Guidelines](https://docs.github.com/en/site-policy/github-terms/github-community-guidelines).
