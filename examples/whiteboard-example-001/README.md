# Whiteboard Example 001

This folder is reserved for the first public example.

The example must be fully synthetic, or explicitly consented and de-identified before publication.

Target contents:

- a final canvas image
- a minimal Prompt Package JSON
- a short, non-sensitive explanation of what was drawn
- optionally a short, consented transcript excerpt
- a list of source evidence for every process conclusion

## Intended purpose

The example should show that a whiteboard session is not just an image.

It is a structured thinking trace whose evidence can be inspected through:

- final canvas semantics
- drawing order
- emphasis
- optional voice explanation

The example must distinguish a text-level process conclusion from an object-level claim. If the drawing does not contain a named or auditable object association, the example should leave that object state unknown.
